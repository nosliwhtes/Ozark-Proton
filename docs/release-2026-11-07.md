Ozark Proton November 7 update: GE-Proton11-12, newer graphics components, and the upstream fixes already integrated into Ozark since October 28.

This is an unofficial, experimental Ozark build. Game compatibility, controller behavior, VR, and performance have not been tested for this release. Keep a previous working Proton version available.

### Changes since October 28

- Updates the GE base from 11-11 to 11-12 and retains the later GE changes already merged into Ozark. These include video decoding and seeking fixes, thread cleanup and synchronization fixes, Wayland input and focus corrections, and Steam overlay improvements.
- Adds opt-in NVIDIA Streamline upgrades with `PROTON_STREAMLINE_UPGRADE=1`; a version string can select a particular release. This replaces the game's `sl.*.dll` files at load time and is not combined with OptiScaler. The existing OptiScaler and FSR4 controls remain available.
- Includes GE's Bluetooth DualSense USB presentation, haptics, and speaker/headphone audio work when Steam Input is disabled. `PROTON_DUALSENSE_BT_AS_USB=0` disables USB presentation; `PROTON_DUALSENSE_BT_HAPTICS=0` disables the synthetic controller audio path. Speaker audio requires libopus at runtime. This describes the included implementation, not an Ozark hardware test.
- Adds Xbox prompts for Rune Factory 5 through `PROTON_STEAM_INPUT_XBOX_PROMPTS`, preserves user-changed umu drive letters, and includes GE's 32-bit Wine OpenXR packaging and prefix-version migration fixes.
- Preserves Ozark's NVIDIA shader-cache defaults, custom game fixes, and checksummed release packaging.

### Withdrawn workaround

Removes the recently integrated `run`/`runinprefix` upscaler workaround, following [GE's upstream reversal](https://github.com/GloriousEggroll/proton-ge-custom/commit/e55060ae05e16e01891a1fef7d110e2ae4648ead). Those launch verbs skip other required Proton setup, so enabling upscalers alone was not a complete fix. Affected Lutris installations need an updated launcher. Normal `waitforexitandrun` upscaler setup remains supported.

This release uses the reviewed Ozark source through PR #28 plus that selective reversal; it does not include all subsequent unreleased GE commits.

### Install

Download the tarball and both checksum files from this release. In the download directory, run:

```sh
sha256sum -c Ozark-Proton-2026-11-07.tar.gz.sha256
sha512sum -c Ozark-Proton-2026-11-07.sha512sum
```

Extract `Ozark-Proton-2026-11-07.tar.gz` into `~/.steam/steam/compatibilitytools.d/`, or `~/.var/app/com.valvesoftware.Steam/data/Steam/compatibilitytools.d/` for Flatpak Steam. Restart Steam and select the build under the game's **Properties → Compatibility**.
